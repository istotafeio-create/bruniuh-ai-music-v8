CLOUDFLARE R2 — PASSO A PASSO

1. Cria/entra numa conta Cloudflare.
2. Abre Storage & Databases -> R2.
3. Cria um bucket:
   bruniuh-ai-music
4. Cria credenciais/API Token com acesso ao R2.
5. Copia para .env.local:
   R2_ACCOUNT_ID
   R2_ACCESS_KEY_ID
   R2_SECRET_ACCESS_KEY
   R2_BUCKET=bruniuh-ai-music

As músicas ficam privadas.
O site cria links temporários para o utilizador ouvir/download.

A free tier Standard atual é muito útil para arrancar com pouco custo.
